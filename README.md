## 🧠 Теоретическое введение

### Что такое Vision Transformer?

**Vision Transformer (ViT)** — это архитектура глубокого обучения, которая применяет механизм **Transformer** (изначально разработанный для обработки текста) к задачам компьютерного зрения.

#### История создания

- **2017**: Введение архитектуры Transformer в статье "Attention is All You Need" для обработки текста
- **2020**: Google Research предложила Vision Transformer (ViT) в статье "An Image is Worth 16x16 Words"
- Показала, что Transformer может превзойти сверточные нейронные сети (CNN) в задачах классификации изображений

#### Ключевая идея

Вместо использования сверточных слоев (как в CNN), ViT:
1. **Разбивает изображение на патчи** (patches) размером, например, 16×16 пикселей
2. **Линеаризует патчи** в последовательность векторов
3. **Обрабатывает последовательность** через Transformer encoder с механизмом self-attention

---

### Механизм Self-Attention

**Self-attention (самовнимание)** — это ключевой механизм в Transformer, который позволяет модели:
- Анализировать отношения между различными частями изображения
- "Обращать внимание" на наиболее важные области
- Захватывать долгосрочные зависимости (в отличие от локальных сверток в CNN)

#### Как работает Self-Attention?

Для каждого патча изображения механизм self-attention вычисляет:

1. **Query (Q)** — "что я ищу?"
2. **Key (K)** — "что я предлагаю?"
3. **Value (V)** — "что я предоставляю?"

Формула self-attention:

```
Attention(Q, K, V) = softmax(Q·K^T / √d_k) · V
```

Где:
- `Q·K^T` — скалярное произведение запросов и ключей (оценивает схожесть)
- `√d_k` — нормализующий коэффициент (размерность ключей)
- `softmax` — преобразует оценки в вероятности (веса внимания)
- Умножение на `V` — взвешенная сумма значений

#### Multi-Head Attention

В ViT используется **Multi-Head Attention** — несколько механизмов self-attention работают параллельно:
- Каждая "голова" (head) изучает различные аспекты данных
- Например, одна голова может фокусироваться на текстуре, другая — на форме
- Результаты всех голов объединяются

### Архитектура ViT

#### 1. Patch Embedding (Разбиение на патчи)

Изображение размером **H×W×C** разбивается на патчи размером **P×P**:

```
Количество патчей = (H/P) × (W/P)
```

Например, изображение 224×224 с патчами 16×16:
- Получается 14×14 = 196 патчей
- Каждый патч содержит 16×16×3 = 768 пикселей

#### 2. Linear Projection (Линейная проекция)

Каждый патч преобразуется в вектор через линейный слой:

```
Патч [16×16×3] → Вектор [768] → Embedding [D]
```

Где `D` — размерность эмбеддинга (например, 768)

#### 3. Positional Encoding (Позиционное кодирование)

Добавляется информация о позиции патча в изображении:

```
Патч Embedding + Positional Embedding = Final Embedding
```

Это важно, так как self-attention сам по себе не учитывает порядок входных данных.

#### 4. CLS Token (Токен классификации)

Добавляется специальный токен `[CLS]` в начало последовательности:
- Его финальное представление используется для классификации
- Аналогично BERT в NLP

#### 5. Transformer Encoder

Последовательность эмбеддингов проходит через стек Transformer блоков:

**Каждый блок содержит:**

```
┌────────────────────────────────────┐
│  Multi-Head Self-Attention         │
│  (механизм внимания)               │
└────────────────────────────────────┘
           ↓
┌────────────────────────────────────┐
│  Layer Normalization               │
└────────────────────────────────────┘
           ↓
┌────────────────────────────────────┐
│  MLP (Feed-Forward Network)        │
│  [Linear → GELU → Linear]          │
└────────────────────────────────────┘
           ↓
┌────────────────────────────────────┐
│  Layer Normalization               │
└────────────────────────────────────┘
```

**Residual connections (skip connections)** добавляются вокруг каждого подслоя.

#### 6. Classification Head (Голова классификации)

Представление `[CLS]` токена на выходе подается в полносвязный слой:

```
[CLS] Output [D] → Linear Layer → Logits [num_classes]
```

### Визуальная схема ViT

```
┌─────────────────────────────────────────────────────────┐
│                  Входное изображение                     │
│                     (224 × 224 × 3)                      │
└─────────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────────┐
│           Разбиение на патчи (16×16)                     │
│      14×14 = 196 патчей, каждый размером 768            │
└─────────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────────┐
│             Linear Projection (Embedding)                │
│          Каждый патч → вектор размера D=768             │
└─────────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────────┐
│     Добавление [CLS] токена и Positional Encoding        │
│           [CLS] + 196 patch embeddings                   │
└─────────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────────┐
│         Transformer Encoder (12 блоков)                  │
│  ┌─────────────────────────────────────┐                │
│  │  Multi-Head Self-Attention (12 голов)│               │
│  └─────────────────────────────────────┘                │
│  ┌─────────────────────────────────────┐                │
│  │     Feed-Forward Network (MLP)      │                │
│  └─────────────────────────────────────┘                │
│                × 12 раз                                  │
└─────────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────────┐
│         Извлечение [CLS] токена                          │
└─────────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────────┐
│          Classification Head (Linear Layer)              │
│                 [D=768] → [6 классов]                    │
└─────────────────────────────────────────────────────────┘
                        ↓
                  Предсказание класса
```

### Преимущества и недостатки

#### ✅ Преимущества Vision Transformer

1. **Глобальное поле зрения**
   - Self-attention анализирует все части изображения одновременно
   - CNN работают локально (поле зрения растет с глубиной сети)

2. **Масштабируемость**
   - Хорошо масштабируется на большие датасеты
   - С ростом данных качество продолжает улучшаться

3. **Интерпретируемость**
   - Attention maps показывают, на что "смотрит" модель
   - Легче понять принятие решений

4. **Унифицированная архитектура**
   - Одна архитектура для различных задач (классификация, детекция, сегментация)
   - Легко адаптируется

5. **Transfer Learning**
   - Предобученные модели отлично переносятся на новые задачи
   - Fine-tuning работает эффективно

#### ❌ Недостатки Vision Transformer

1. **Требует большие данные**
   - Нужны миллионы изображений для обучения с нуля
   - На малых датасетах CNN часто лучше
   - **Решение:** Fine-tuning предобученных моделей

2. **Вычислительная сложность**
   - Self-attention имеет квадратичную сложность O(n²) по количеству патчей
   - Требует больше памяти GPU
   - **Решение:** Использование меньших моделей (ViT-tiny, ViT-small)

3. **Слабая индуктивная предвзятость**
   - CNN имеют встроенные предположения (локальность, трансляционная инвариантность)
   - ViT должен выучить это из данных
   - **Решение:** Предобучение на больших датасетах

## 📊 Подготовка датасета

### Автоматическое разделение

Код автоматически разделяет датасет на:
- **70% — Train** (обучающая выборка)
- **15% — Validation** (валидационная выборка)
- **15% — Test** (тестовая выборка)

### Data Augmentation

Для обучающей выборки применяются аугментации:
- Random Crop (случайный crop)
- Random Horizontal Flip (горизонтальное отражение)
- Random Vertical Flip (вертикальное отражение)
- Random Rotation (поворот ±15°)
- Color Jitter (изменение яркости, контраста, насыщенности)

Это помогает модели лучше обобщаться и снижает переобучение.

# Запустите все ячейки в notebook

# - Early Stopping (остановка при переобучении)
# - Learning Rate Scheduling (автоматическая подстройка LR)

### Загрузка обученной модели

```python
import torch
from transformers import ViTForImageClassification

# Загрузка модели
checkpoint = torch.load('vit_radar_classifier_final.pth')

# Создание модели
model = ViTForImageClassification.from_pretrained(
    checkpoint['config']['model_name'],
    num_labels=checkpoint['config']['num_classes']
)

# Загрузка весов
model.load_state_dict(checkpoint['model_state_dict'])
model.eval()

# Получение названий классов
class_names = checkpoint['class_names']
```

### Предсказание на новом изображении

```python
from PIL import Image
from torchvision import transforms

# Загрузка изображения
image = Image.open('path/to/image.jpg').convert('RGB')

# Трансформации
transform = transforms.Compose([
    transforms.Resize((224, 224)),
    transforms.ToTensor(),
    transforms.Normalize(
        mean=[0.485, 0.456, 0.406],
        std=[0.229, 0.224, 0.225]
    )
])

# Применение трансформаций
image_tensor = transform(image).unsqueeze(0).to(device)

# Предсказание
with torch.no_grad():
    outputs = model(pixel_values=image_tensor)
    logits = outputs.logits
    probs = torch.nn.functional.softmax(logits, dim=1)
    confidence, predicted = torch.max(probs, 1)

print(f"Класс: {class_names[predicted.item()]}")
print(f"Уверенность: {confidence.item() * 100:.2f}%")
```

## ❓ FAQ

### В: Нужно ли GPU для обучения?

**О:** Да, настоятельно рекомендуется. Vision Transformer содержит ~86M параметров. На CPU обучение займет очень много времени. Google Colab предоставляет бесплатный GPU.

### В: Сколько времени займет обучение?

**О:** На Google Colab с GPU T4:
- ~2-3 минуты на эпоху для 1600 изображений
- С Early Stopping обычно 20-30 эпох
- Итого: 1-1.5 часа

### В: Что делать если не хватает памяти GPU?

**О:** Уменьшите `BATCH_SIZE` в конфигурации:
```python
BATCH_SIZE = 8  # или даже 4
```

### В: Можно ли использовать для других задач?

**О:** Да! Код легко адаптируется:
- Измените `NUM_CLASSES` на ваше количество классов
- Поменяйте путь к датасету
- Все остальное останется без изменений

### В: Как улучшить точность?

**О:** Попробуйте:
1. Увеличить количество эпох (если есть переобучение)
2. Использовать больше данных
3. Настроить Data Augmentation
4. Попробовать другую предобученную модель (ViT-Large)
5. Экспериментировать с Learning Rate
